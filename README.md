# CuboSites marketing site (`www.cubosites.com`)

Next.js App Router marketing site for CuboSites — SEO metadata, Lenis smooth scroll, Framer Motion, and Recharts.

## Develop

```bash
cd cubesites_web
npm install
npm run dev
```

Default: [http://localhost:3000](http://localhost:3000)

## Configure product URLs

Edit `src/lib/site.ts`:

- `appUrl` — contractor PWA (default `https://app.cubosites.com`)
- `adminUrl` — Super Admin (default `https://admin.cubosites.com`)
- Contact: `hello@cubixmet.com`, `+91 89215 92742`

## Build

```bash
npm run build && npm start
```
